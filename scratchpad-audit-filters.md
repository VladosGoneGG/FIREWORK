# Audit: Category/Filter Sidebar, Sort, Search, Chips, Accordion

Scope: category/filter sidebar, sort controls, search input, filter chips/badges, accordion/collapsible sections (desktop + mobile filter drawer).

ORIGINAL = `D:\Projects\Frontend\FIREWORK-original` (pre-migration, commit 27e2560), served at http://localhost:5173
MIGRATED = `D:\Projects\Frontend\FIREWORK` (Next.js, branch `migration/nextjs`), served at http://localhost:3000

Browser verification: confirmed live at http://localhost:3000/category/salyuty via JS DOM query — the only interactive controls on the page are the two `SortLinks` anchors (`дешевле сначала` / `дороже сначала`); no "фильтр" button, no filter panel, no chips, no accordion exist anywhere in the migrated DOM. Original app confirmed via DOM query to have a `фильтр` button (`btn-firework-filter` class) inside `SubcategoryPanel` header at 1040px+ breakpoint (interactive click-to-open verification was attempted but the headless Browser pane in this environment would not composite/report a real viewport, so the open-state animation was verified from source instead — see transition values below, read directly from the `motion` props).

## Headline finding

The migrated app has **no filter UI at all**. `lib/filters.ts` implements a full filter engine (price/duration range, manufacturers, shots, power buckets, ignitionType, view, size, tags, inStockOnly, hasCertificate) but nothing in `app/` or `components/` renders controls for any of it except category/subcategory links and 2-way price sort. `components/ui/Dialog.tsx` even says so directly in its own comment (line 12): "every overlay in the app (cart drawer now, **search/filters later**)". The entire filter sidebar, its accordion sections, tag editor, dual-range sliders, checkbox chips, and open/close animation were dropped, not simplified.

## Summary of the biggest gaps

1. **The entire filter feature is missing in the migrated app.** `lib/filters.ts` (`D:\Projects\Frontend\FIREWORK\lib\filters.ts`) implements the full matching engine — price/duration range, manufacturer, shots, power, ignitionType, view, size, tags — but no component renders any control for it. Confirmed live: `http://localhost:3000/category/salyuty` has zero "фильтр" affordance in the DOM. `components/ui/Dialog.tsx:12` literally says filters are deferred to "later." This means all of the original's `SubcategoryOverlay`/`FilterContent`/`FilterSection`/`WhiteCheckRow`/`TagsEditor`/`RangeDual`/`BadgeInput`/`FilterFooter` component tree (`D:\Projects\Frontend\FIREWORK-original\src\components\SubcategoryOverlay\`) — including its `framer-motion` open/close animation (`height`/`opacity`/`y`, 0.18–0.25s `easeOut`) — has no counterpart at all, not even a flattened/instant one.
2. **Sort dropdown was replaced with plain links.** Original `SortDropdown.jsx` is a full custom listbox (hover/active/keyboard states, animated chevron). Migrated `SortLinks.tsx` is two `<Link>`s — functionally equivalent (same 2 sort keys) but visually and interactively a completely different control, done deliberately per the migration's URL-first design.
3. **Search lost its icon, animated placeholder, debounce, and live suggestions.** `SearchModal.jsx` (720px modal with keyboard-navigable live results) has no counterpart; `SearchForm.tsx` is a bare GET form.
4. **Minor styling drift on what does exist**: `rounded-[20px]` → Tailwind's `rounded-2xl` (16px) on category nav and search input; category-nav shadow alpha `0.2` → `0.08`.
