## Biggest gaps (priority)

1. **Success screen lost its icon** — original shows a dedicated success SVG graphic in a centered overlay; migrated is text-only. Highest-visibility regression in the whole checkout flow.
2. **Two brand fonts (Barlow, Inter) and the filter-button gradient class (`.btn-firework-filter`) were dropped without documentation** — only Calibri's removal is explained (licensing). Barlow is still referenced live by 4+ original components (product meta, footer) and Inter by 3 (subcategory/product page), so this is lost typography, not dead code cleanup.
3. **Radius/shadow flattening at scale** — the original's brand `rounded-[10px]`/`rounded-[20px]` and custom `shadow-[...]` values appear in 56 original source files; migrated only overrides Tailwind defaults in 4 files. Most surfaces now render with generic Tailwind `rounded-lg`/`shadow-sm` instead of the brand's softer/rounder look.
4. **Checkout field validity dots removed** and the delivery-toggle active color drifted from `#bd52e9` to `#c054eb` (two different theme tokens swapped) — small but concrete visual/interaction regressions in a form users actually submit money-adjacent data through.
5. Secondary brand-gradient usages (`Qty.jsx` stepper hover gradients, `PriceQtyButton`'s 4 stock-state gradients, cart-icon fill gradient) don't appear to have been carried over at all.
